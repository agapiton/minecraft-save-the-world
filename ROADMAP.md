# Minecraft: Save the World — Roadmap

Модпак для Minecraft в стиле Fortnite: Save the World. Forge 1.20.1.

---

## Игровая прогрессия

Незер и Энд — не «другая игра», а **экспедиции за ресурсами, без которых база не переживёт следующую стадию заражения**. Расписание Hordes и эволюция Spore идут по таймеру, поэтому откладывать вылазки бесконечно нельзя.

### Тир 0. Первые ночи (≈ дни 1–7)
Деревянные стены, ловушки, луки, первые запасы еды. Нападает обычная нежить, заражения почти нет.
**Цель:** выжить и найти место под базу.

### Тир 1. Периметр (≈ дни 7–20)
Ядро периметра I на угле/древесном угле, ратуша MineColonies, первые механизмы Create, коксовая печь IE. Приходят первые заражённые Spore.
**Цель:** зажечь ядро и завести колонию.

### Тир 2. Индустрия и Незер (≈ дни 20–40)
Первая экспедиция в Незер. Кварц, золото, огненные стержни и незер-материалы нужны (через KubeJS) для турелей IE, дизельных генераторов, **Ядра II** (больший радиус, биодизель) и оптики камер SecurityCraft.
Незер опасен: через In Control! там спавнятся заражённые Spore — «зона, куда инфекция уже добралась».
**Аванпостный маяк** — переносное ядро с малым радиусом и высоким расходом топлива. Топливо на вылазку нужно привезти → логистика.

### Тир 3. Экспансия (≈ дни 40–70)
Поезда Create и самолёты Immersive Aircraft связывают базу с шахтами и аванпостами. Охота на Proto Hivemind: CDU и зачистка ульев. Древние обломки — для лучшей брони и ствольных деталей TaCZ. Корабли Valkyrien Skies как мобильные базы.
**Цель:** не дать заражению захватить карту.

### Тир 4. Энд (≈ дни 70+)
Эндер-материалы открывают **Ядро III**, радар дальнего действия, дальние камеры и тяжёлые инструменты зачистки (ядерный заряд Spore Inquisition — если датапак пройдёт тесты). Элитры для воздушной разведки. Энд — очаг, который питает улей.

### После дракона — бесконечный режим
Убийство дракона **переключает мир в следующую фазу**: Hordes переходит на эндгейм-таблицы волн, заражение ускоряется, игроки получают лучшие инструменты зачистки. Дальше — очищение мира чанк за чанком.
Способ переключения (скрипты Hordes или флаг KubeJS) — проверить на этапе 6.

> Дни ориентировочные: задаются расписанием Hordes и уточняются на плейтестах.

## План разработки

Итого до плейтеста ≈ 30–45 вечеров; основное время — этапы 2, 3 и 6.

### Этап 0. Подготовка (1–2 вечера)
- [x] Инстанс CurseForge на Forge 1.20.1
- [x] Git-репозиторий (`config`, `kubejs`, `defaultconfigs`) + GitHub
- [ ] Локальный тестовый сервер
- [ ] Способ фиксировать список модов (экспорт CurseForge или packwiz)

**Готово, когда:** клиент и сервер запускаются, изменения конфигов коммитятся в git.

### Этап 1. Скелет (2–3 вечера)
- [ ] Create, Immersive Engineering, MineColonies
- [ ] KubeJS, JEI, Jade
- [ ] Моды оптимизации
- [ ] Никакой угрозы — только проверка стабильности

**Готово, когда:** мир с колонией и механизмами час работает на сервере без крашей и заметных просадок.

### Этап 2. Угроза (4–6 вечеров)
- [ ] Spore
- [ ] The Hordes (зомби-инфекция отключена)
- [ ] Improved Mobs
- [ ] Spore Inquisition (опционально)
- [ ] Таблицы волн по дням, включая день появления летающих врагов
- [ ] Скорость эволюции Spore
- [ ] Ломание блоков по уровням мобов

**Готово, когда:** при перемотке времени волны приходят в свои дни, а без обороны база падает примерно ко второй неделе.

### Этап 3. Ядро периметра (3–5 вечеров) ⚠️ самый рискованный
- [ ] Блок ядра на KubeJS
- [ ] Расход топлива
- [ ] Отмена спавна в радиусе
- [ ] Три уровня ядра + аванпостный маяк
- [ ] Ядро не блокирует волны Hordes и не нагружает сервер

**Готово, когда:** ядро гаснет без топлива, внутри не спавнятся мобы, орды доходят до стен.
**Запасной план:** Torchmaster с дорогим рецептом.

### Этап 4. Экономика (4–6 вечеров)
- [ ] Farmer's Delight
- [ ] Tough As Nails
- [ ] Serene Seasons
- [ ] Tom's Simple Storage
- [ ] Цепочка «урожай → биодизель → ядро и генераторы»
- [ ] Напитки утоляют жажду
- [ ] Проверка ферм колонии зимой

**Готово, когда:** у базы ощутимые траты, но выживание не превращается в рутину.

### Этап 5. Оборона и обнаружение (3–4 вечера)
- [ ] SecurityCraft (неразрушимые блоки убраны из крафта)
- [ ] Турели IE
- [ ] TaCZ (патроны только с линии IE, самое мощное оружие убрано)
- [ ] Ловушки Create
- [ ] Связка «датчик → сирена → ворота»

**Готово, когда:** база без игроков выдерживает средние волны, а сильные — только с их участием.

### Этап 6. Измерения в прогрессии (4–6 вечеров)
- [ ] Рецепты KubeJS с незер-компонентами (Ядро II, турели, оптика)
- [ ] Рецепты KubeJS с эндер-компонентами (Ядро III, радар, броня)
- [ ] Спавн заражённых в Незере и Энде через In Control!
- [ ] Переключение в эндгейм после дракона

**Готово, когда:** без Незера нельзя собрать Ядро II, без Энда — Ядро III, а в Незере без аванпостного маяка очень тяжело.

### Этап 7. Транспорт и погода (3–4 вечера)
- [ ] Steam 'n' Rails
- [ ] Immersive Aircraft
- [ ] Valkyrien Skies + Eureka (отдельно, проверка совместимости с Create и Spore)
- [ ] Weather, Storms & Tornadoes со слабым разрушением

**Готово, когда:** корабль с игроками пролетает над заражённой зоной и возвращается, сервер не падает.

### Этап 8. Квесты-ориентиры (2–3 вечера)
- [ ] FTB Quests: по главе на каждый тир
- [ ] Все задания открыты, награды символические

**Готово, когда:** новичок по книге квестов понимает, на каком он этапе и куда двигаться.

### Этап 9. Плейтест с друзьями (2–3 недели реальной игры)
- [ ] Сила волн под 2–4 игрока
- [ ] Производительность больших колоний
- [ ] Производительность поздних фаз Spore

**Готово, когда:** группа доходит до Энда без ощущения, что игра слишком лёгкая или тупо затянутая.

### Этап 10. Релиз и поддержка
- [ ] Серверная сборка
- [ ] Автобэкапы мира (особенно из-за погоды и Valkyrien Skies)
- [ ] Список изменений (changelog)
- [ ] Обновления модов — только через тестовый инстанс
